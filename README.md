## GitHub Pages-də yerləşdirmə

1. Bu qovluğu GitHub-da yeni repository yaradıb yükləyin
2. Repository **Settings → Pages** bölməsinə gedin
3. Source olaraq `main` branch seçin
4. Bir neçə dəqiqə sonra saytınız hazır olacaq:
   `https://USERNAME.github.io/REPO-ADI`

## Musiqi əlavə etmək

1. Sevdiyiniz mahnını `music.mp3` adı ilə yükləyin
2. Faylı `index.html` ilə eyni qovluğa qoyun
3. Saytı yeniləyin və altdakı **Musiqi** düyməsinə basın

## Fayllar
- `index.html` — əsas səhifə
- `style.css` — dizayn və animasiyalar
- `script.js` — ürəklər və musiqi idarəsi
- `music.mp3` — (özünüz əlavə edin)
